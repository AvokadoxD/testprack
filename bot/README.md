# Бот «Яблочный дозор» — MVP для теста

Рабочий Telegram-бот для недель 1–6 теста. Класс качества в MVP ставит человек-оператор: это «ручная» имитация сервиса, которую задание прямо разрешает. Подсказка по фото считает долю бурых пикселей и помогает оператору, но не заменяет его.

## Запуск за 10 минут

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя, например `yabloko_dozor_test_bot`. Скопируйте токен.
2. Узнайте свой Telegram ID у @userinfobot — это ID оператора.
3. Установите зависимости и запустите (нужен Python 3.10+):

```bash
cd bot
pip install -r requirements.txt
BOT_TOKEN=123:ABC ADMIN_IDS=111111111,222222222 python bot.py
```

Бот работает, пока запущен скрипт. На время теста подойдёт ноутбук или сервер за 188 ₽/мес.

## Что делает садовод

`/start` → «🍎 Сдать яблоки» → фото → геопозиция → объём → подтверждение. Когда соберётся рейс, бот присылает день вывоза и QR-бирки на мешки. После приёмки садовод получает сообщение с весом и суммой.

## Команды оператора

| Команда | Что делает |
|---|---|
| кнопки под фото заявки | поставить класс: столовое, техническое, падалица, гниль (гниль — отказ) |
| `/clusters` | заявки, сгруппированные в радиусе 10 км, и сколько не хватает до 1 000 кг |
| `/run 1 четверг 10:00–12:00` | собрать рейс из кластера 1: маршрут, стоимость «Газели», рассылка садоводам с QR-бирками |
| `/intake 12 118.5` | записать вес заявки №12 на приёмке и сообщить садоводу сумму |
| `/act 1` | черновик закупочного акта по рейсу 1 (CSV, поля по форме ОП-5) |
| `/export` | все заявки в GeoJSON — открыть на geojson.io или в карте переработчика |
| `/stats` | метрики теста: заявки, отказы, принятый вес, ₽ логистики на 1 кг |

## Настройки (переменные окружения)

`PRICE_GARDEN=10`, `PRICE_PROC=22`, `MIN_RUN_KG=1000`, `CLUSTER_KM=10`, `PROCESSOR_LAT`/`PROCESSOR_LON` — координаты переработчика-партнёра. В неделю 5 цену садоводу можно поменять на 8 или 12 ₽ для теста цены.

## Метрики для слайда 8

- `/stats` → сколько заявок, какая доля отклонена как гниль, логистика ₽/кг.
- Совпадение подсказки по фото с классом оператора: сохраняйте пары (подсказка → класс) — это первая проверка технологии.
- Неделя 4: те же фото плюс открытый датасет → обучение классификатора в Google Colab (YOLOv8-cls) → точность против оценки технолога.

Бот не принимает платежи: деньги садоводам переводит переработчик по СБП, бот только считает суммы и готовит акт.
