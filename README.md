# «Яблочный дозор» — 2 этап кейс-чемпионата «Ключ»

Команда «ЗОЖ-дозор» · бизнес-направление «Накормить будущее: агротех и фудтех от поля до стола» · Псковская область · 2026

**Решение:** Telegram-бот и карта. Садовод фотографирует излишки яблок, ИИ оценивает качество, платформа собирает заявки соседей в один рейс «Газели» и везёт яблоки переработчику: 22 ₽/кг с доставкой, из них 10 ₽ садоводу. Категория РСХБ: «Маркетплейсы».

## Что в репозитории

| Папка | Что внутри |
|---|---|
| `prezentaciya/index.html` | презентация: 10 слайдов + 5 приложений, анимации, текст выступления по клавише N, работает без интернета |
| `prezentaciya/Яблочный_дозор_ЗОЖ-дозор.pdf` | PDF для сдачи (формат задания) |
| `prezentaciya/deck.src.html` | исходник презентации — правьте здесь |
| `prototip/index.html` | кликабельный прототип: бот садовода, оценка фото, карта переработчика, сборка рейса, закупочный акт, калькулятор рейса |
| `bot/` | код Telegram-бота для теста на 6 недель, инструкция — `bot/README.md` |
| `tools/` | сборка HTML со встроенными шрифтами (`build.py`) и экспорт PDF (`export.js`) |

## Как показывать

Откройте `prezentaciya/index.html` в Chrome. Управление: → или пробел — дальше, ← — назад, F — на весь экран, N — текст выступления и секундомер (для репетиций).

## Как править и пересобрать

1. Правьте текст в `prezentaciya/deck.src.html` (или `prototip/prototype.src.html`). Места для ваших данных помечены жёлтой плашкой «ВПИСАТЬ».
2. Соберите HTML: `python3 tools/build.py` (для QR-бирок в прототипе нужен `pip install qrcode`).
3. Сделайте PDF: `node tools/export.js` (нужен Playwright). Без программирования: откройте `index.html` в Chrome → Ctrl+P → «Сохранить как PDF», поля «Нет», фон включить.

## Что команда делает сама

Интервью (15+, из них 5+ с практиками), проверку прототипа на людях, первый рейс, обучение классификатора на своих фото, фото и данные команды на слайде 10. Без этого критерии 1 и 7 получат не выше 1 балла. Сценарий выступления, ответы на вопросы жюри, сценарии интервью и план теста — в документе команды.

Использование ИИ раскрыто на слайде 10 и в приложении П4: Claude (Anthropic) помогал с поиском данных, текстами, вёрсткой и кодом. Каждую цифру перед защитой сверьте по первоисточнику — ссылки в приложении П5 и в документе команды.
