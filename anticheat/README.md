# StrazhAC — серверный античит для Paper 1.21.11

Готовый плагин: [`release/StrazhAC-1.0.0.jar`](release/StrazhAC-1.0.0.jar).

## Установка

1. Сервер: **Paper 1.21.11**, Java 21.
2. Поставьте плагин **PacketEvents 2.14.0 или новее** (`packetevents-spigot`, Modrinth / SpigotMC) — StrazhAC без него не запустится.
3. Положите `StrazhAC-1.0.0.jar` в `plugins/` и перезапустите сервер.
4. Настройки — `plugins/StrazhAC/config.yml`. Параметры каждой проверки дописываются в раздел `checks` автоматически при первом запуске; после правок — `/strazh reload`.

Рекомендуется: сначала поиграть несколько дней в режиме только алертов (`punishments.enabled: false`), посмотреть логи `plugins/StrazhAC/logs/` и подстроить пороги под свой сервер.

## Команды и права

| Команда | Что делает |
|---|---|
| `/strazh alerts` | вкл/выкл алерты (наведение — детали, клик — телепорт к игроку) |
| `/strazh verbose` | все флаги без задержки |
| `/strazh info <игрок>` | клиент, версия, пинги (keepalive / транзакции), транспорт, нарушения |
| `/strazh debug <игрок>` | расчёты движка движения в action bar (для подстройки порогов) |
| `/strazh exempt <игрок> <сек, 0=навсегда> [all\|movement\|combat\|world\|player\|packet\|misc\|id]` | исключение |
| `/strazh unexempt <игрок> [ключ]` | снять исключение |
| `/strazh resetvl <игрок>`, `/strazh top`, `/strazh checks`, `/strazh reload` | |

Права: `strazh.alerts` (алерты), `strazh.admin` (все команды), `strazh.bypass` (полный обход — не выдавать игрокам).

## Машины на Skript и другие плагины

Совместимость с кастомными машинами встроена:

- пока игрок сидит на сиденье с тэгами `car_seat`, `car_main`, `moped_main`, `car_id_*`, `car_seat_*`, `car_part_*`, `moped_id_*` (список в `vehicles.seat-tags`) или на любой display/armor_stand/interaction-сущности, проверки движения и аима не работают;
- повороты камеры машиной (`ClientboundPlayerRotationPacket` каждый тик) распознаются по ответному эху клиента и не считаются движением мыши;
- после высадки — льготный период (`vehicles.dismount-grace-ticks`, для кастомного транспорта вдвое длиннее), телепорт к двери обрабатывается как обычный телепорт;
- скорость от сервера (сбитые пешеходы, взрыв машины) учитывается через транзакции;
- отменённые сервером Q (гудок), F (фары), ПКМ ключом — нормальные действия.

Если какой-то механике нужно временно отключить проверки, из Skript без Java:

```
add "strazh_exempt" to scoreboard tags of player             # все проверки
add "strazh_exempt_movement" to scoreboard tags of player    # только движение
remove "strazh_exempt_movement" from scoreboard tags of player
```

Или через skript-reflect: `ru.strazh.ac.api.StrazhAPI.exempt(player, "movement", 3000)` (мс; 0 — до `unexempt`).
Для других плагинов есть события `StrazhFlagEvent` (можно отменить) и `StrazhPunishEvent` (можно изменить команды).

## Как устроено

- **Транзакции** (ping/pong) каждый тик и сразу после важных пакетов. Id случайные 32-битные: читы определяют античиты по диапазону id. Всё, что сервер меняет у клиента (скорость, телепорты, повороты камеры, сущности, способности, атрибуты, окна), привязано к окну «до/после» ответа клиента — это и есть компенсация пинга.
- **Три независимых пинга**: KeepAlive, транзакции и RTT по ядру ОС (TCP_INFO, клиент его не подделает). Blink, FakeLag, BackTrack и PingSpoof дают между ними расхождение.
- **Грамматика тика 1.21.2+**: ванильный клиент шлёт пакеты в строгом порядке `[слот] [действия] [ввод] [спринт] [движение] [конец тика]`, а клики по окнам — только между тиками. Большинство «обходных» режимов приватных клиентов этот порядок нарушает.
- **Модель движения** (главный поток, чтение мира без загрузки чанков): верхняя граница горизонтальной скорости по физике 1.21 (инерция с трением, ускорение, спринт-прыжок, скорость от сервера, толкание), вертикаль по гравитации и силе прыжка, опора под ногами, вход в блоки. В неопределённых ситуациях (жидкости, лестницы, паутина, поршни, элитры, тризубец, транспорт, свежие изменения блоков, эффекты в пути) флагов нет.
- **Бой**: хитбокс цели — объединение всех позиций, которые клиент мог видеть (транзакции + интерполяция), но не старше базового пинга + запас (против BackTrack). Луч взгляда тика удара обязан попадать в хитбокс.
- **Зонд «тихого» аима**: в бою сервер иногда поворачивает камеру на 0°. Клиент отвечает углами камеры, и у silent-ауры они не совпадают с отправляемой ротацией.
- **Ловушка-NPC**: подозреваемому показывается фейковый игрок строго за спиной (с ником в табе, реальным подписанным скином, правильным UUID и снаряжением). Человек не может навести на него прицел, аура бьёт.
- **Смягчение**: при подозрении в бою часть ударов тихо отменяется ещё до наказания (`mitigation`). Нарушения движения — откат на последнюю честную позицию.

## Сборка из исходников

```
./gradlew build            # нужны repo.papermc.io и repo.codemc.io
```

Офлайн-сборка (без доступа к репозиториям Paper/CodeMC): `./gradlew build -PlocalLibs=<папка с paper-api.jar и packetevents.jar>`.
Тесты: `./gradlew test` (модель физики на ванильных траекториях, транзакции, трекеры, смоук всех проверок).
Руководство для разработки проверок: [`docs/DEV_GUIDE.md`](docs/DEV_GUIDE.md).

## Ограничения (честно)

- Плагин **не проверялся на живом сервере**: в среде разработки нет доступа к загрузке Paper. Перед продом погоняйте на тестовом сервере с алертами без наказаний.
- Движок движения — «модель границ» плюс проверка направления ускорения по клавишам, а не полная попакетная симуляция как у Grim. Обходы в пределах физически возможной скорости и направления он не видит. Элитры проверяются только без фейерверков; тризубец и левитация пока не проверяются.
- Проверки, помеченные как экспериментальные (Aim A, Transaction C), по умолчанию только алертят.
- Клиенты Bedrock (Geyser) по движению и бою только логируются.
- RTT по ядру доступен, только если сервер работает на epoll (Linux) без прокси; за BungeeCord/Velocity это сравнение не работает.
